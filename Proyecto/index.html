Tema: Sistema de Citas para Revisión Vehicular.

Avance: Segundo.

En este proyecto Final, se desarrollará un sistema de citas para la revisión vehicular, permitiendo a los usuarios agendar sus citas de manera eficiente y sencilla. Contará con Usuario con Perfil de Cliente y Administrador. Además de tener una interfaz amigable, el sistema contará con funcionalidades para gestionar y consultar las citas agendadas. Finalmente el sistema Genera una Factura, con los datos del Cliente y Servicio Solicitado.

Contenidos:

  1. Formularios.
  2. Tablas.
  3. Estilos CSS.
  4. Conexión a SupaBase.
  5. Implementación de CRUD.
  6. Implementación Login.
  7. Implementación de Facturación.
