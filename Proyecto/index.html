Tema: Sistema de Citas para Revision Vehicular.

Avance: Segundo.

En este proyecto Final, se desarrollara un sistema de citas para la revision vehicular, permitiendo a los usuarios agendar sus citas de manera eficiente y sencilla. Contara con Usuario con Perfil de Cliente y Administrador. Ademas de tener una interfaz amigable, el sistema contara con funcionalidades para gestionar y consultar las citas agendadas. Finalmente el sistema Genera una Factura, con los datos del Cliente y Servicio Solicitado.

Contenidos:

  1. Formularios.
  2. Tablas.
  3. Estilos CSS.
  4. Conexion a SupaBase.
  5. Implementacion de CRUD.
  6. Implementacion Login.
  7. Implementacion de Facturacion.
